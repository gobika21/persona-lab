Can the agents be trusted?

Every agent version is scored on a benchmark of 4 demo websites with 12 planted barriers and 5 tasks whose outcome is known for each persona, including an accessible control site to catch false alarms. Agents are compared with what page rules alone can find.

      Task outcomes

      Did the agent reach the right verdict, and did it really finish? "Verified" is checked from the pages it reached and the answer it gave, not from what it claims.

      Method

      Planted barriers

      Small realistic sites (hotel, shop, clinic, library) with known problems: a mouse-only "Book" button, color-only product variants, a day picker without keyboard access, unlabeled fields and more. The library site is fully accessible, so anything reported there is a false alarm.

      Objective outcomes

      Each task has a success check, such as "reached confirmed.html" or "answer contains 10:00". That separates agents that finish from agents that only claim to (false success).

      Matching findings

      A finding counts when it names the right element and the right kind of problem (keyword rules in ground_truth.json), or optionally via an LLM judge. Run it yourself: python -m personalab.evals agents --label my-change.
